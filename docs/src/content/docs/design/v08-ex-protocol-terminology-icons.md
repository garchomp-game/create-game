## 目的

固有スキルは通常ビルド完成後に初めて提示されます。この時点で新しい英語用語を
まとめて覚えさせず、「何をすると」「何が起きるか」をカードだけで判断できる状態を
目指します。内部ID、保存schema、telemetry eventは変更せず、表示層だけを整理します。

## 表示語

一般概念は日本語へ統一します。

| 旧表示 | 採用表示 | 理由 |
| --- | --- | --- |
| Protocol | 固有スキル | 選択対象の役割をそのまま示す |
| Evolution I / II | 強化1 / 強化2 | 選択順を短く示す |
| Mastery | 完成能力 | 2段階強化後に自動解禁される結果を示す |
| Charge | 準備 / 準備回数 | 発動可能かを日本語で判断できる |
| Cooldown | 再使用まで / 再装填 | 残り時間の意味を示す |
| RMB | 右クリック | キーの場所を直接示す |

`Pulse`、`Spread`、`HP`、`XP`、`EX`は既存HUDと一致する短い固有語として維持します。
各能力の日本語名も固有名として維持します。

「集束」「反射」「貫通」「外縁弾」は戦闘ルールを表すため残しますが、初出カードでは
具体的な行動を併記します。たとえば集束条件は「最大の1段前」ではなく
「同じ敵へ3回続けて当てる」と表示します。

## 発動条件の正本

交差導線と赤熱炉心の条件表示は、固定文言を持ちません。
実際の判定と同じ`getProtocolFocusTriggerStacks()`へ、現在の
`pulseFocusMaxStacks`とカタログの`focusTriggerStacksBelowMaximum`を渡して生成します。

現候補は完成Pulse buildで最大4、MAX-1を採用しているため3回です。12 seed比較では
MAX条件の成立hit中央値5に対し、MAX-1は38でした。MAX-2まで緩和せず、
「成立を観測できるが常時主火力にはならない」位置を維持します。

## アイコン

6種類それぞれにA / Bの2案を用意し、A案を選択カードへ仮採用しました。

| 固有スキル | A案の形 | 読ませたい意味 |
| --- | --- | --- |
| 交差導線 | 2点を結ぶ斜線 | 記録地点と次の敵を結ぶ |
| 反跳過給 | 壁で折れる軌道 | 反射後の弾を強化する |
| 赤熱炉心 | 炉心と稲妻 | HPを代償に火力を得る |
| 全幅潮汐掃討 | 広い二重波 | 広範囲を一斉掃射する |
| 防波扇 | 壁から前へ押す矢印 | 近距離の敵を押し戻す |
| 護壁扇 | 盾と扇形 | 外縁弾で敵弾を防ぐ |

SVG symbolは単色・2px strokeで、16 / 20 / 24pxでも輪郭が崩れない構成です。
Pulseは水色、Spreadは黄色という既存の武器色を使い、色だけに依存せず形を変えます。
選択カードでは22px固定とし、hoverやactiveでカード寸法を変えません。

## 採否

A案は可読性候補として採用します。最終アートではなく、初見テストで
「名前を読まずに同じ能力を再選択できるか」を確認するための識別記号です。
識別率が低い能力だけを差し替え、6種類を一括して再設計しません。
