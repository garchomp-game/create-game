## 1回のラン

1. モード、ステージ、開始武器を選ぶ。
2. 最小構成のCOREとしてアリーナへ入る。
3. 移動と照準を行い、敵を倒す。
4. 戦闘データとしてXPを、立て直しの選択肢として回復を回収する。
5. レベル上昇時に強化を選ぶ。
6. 敵構成、出現方向、危険度の変化へ対応する。
7. 通常ビルド、武器固有能力、EX進行を伸ばし、一戦内のCORE完成を目指す。
8. HPが0になるか、作戦条件を達成するとランが終わる。
9. リザルトでスコア、死因、CORE構成、自己記録との差、次に変える行動を確認する。

現在はStory / Endless / Practiceの3導線、Story初期作戦、ボス撃破型の最終遠征、
Pulse / Spreadの開始武器、一戦内25ランクとEX進行が動作します。
10分で記録が途絶え11分で勝利する第1キャンペーンは未実装です。
一戦内成長の経路は実装済みですが、通常25ランクが収束する現状で
「自分のCOREを完成させた」と感じるかは未検証です。

## 判断の時間間隔

| 時間幅 | 主な判断 |
| --- | --- |
| 1から5秒 | どこへ避け、どの敵を狙うか |
| 10から30秒 | ピックアップを取りに行くか、防御行動を温存するか |
| 30から90秒 | ビルドをどの方向へ伸ばすか |
| 2から4分 | 特殊な敵構成やエリートへどう備えるか |
| 6から10分 | ボス撃破、ステージクリア、追加危険度のどれを狙うか |

敵数が増えるだけの時間を長くせず、長時間ランでも最後の意味ある判断から90秒以上空かない状態を目標とします。

## ランをまたぐループ

1. リザルトと履歴から改善点を確認する。
2. 次に変える位置、射線、標的順、回収判断を一つ決める。
3. 別の武器、構成、作戦、チャレンジを選ぶ。
4. 初回クリアや短い目標によって、新しい遊び方を固定解禁する。
5. 自己記録、作戦記録、武器熟練度を更新する。

ラン中に得た攻撃力、HP、強化、装備は持ち越しません。恒久攻撃力を積み上げる
ことではなく、プレイヤー自身の上達、新しい遊び方、比較可能な挑戦を増やします。

## モードごとの役割

| モード | 一戦の目的 | ラン後に残すもの |
| --- | --- | --- |
| Story | 異なる危機を学び、有限の作戦限界を越える | clear、固定解禁、必要な作戦記録 |
| Endless | 完成した操作とCOREで限界へ挑む | PB、履歴、条件別ランキング |
| Practice | 操作、敵、武器、設定を安全に試す | Standard記録へ介入しない学習 |

Storyは素材や装備を集める周回場所にしません。同じ作戦へ戻る理由は、
別武器、別構成、PB、評価、戦術改善です。

## 現在の拡張点

- ステージごとの地形、敵構成、クリア条件。
- 開始武器と武器固有強化。
- 短時間アイテムと回復判断。
- エリート、ボス、特殊な敵出現パターン。
- 危機を反撃、回収、位置改善へ変える局面。
- チャレンジ、武器熟練度、プロフィール統計。
