## 目指すゲーム

`Arena Core` は、1画面の見下ろし型アリーナで四方の圧力を読み、
一戦の中でCOREを形成して作戦限界を越える、手動照準のPvEアリーナシューターです。

製品全体のコンセプトは次の一文へ固定します。

> **包囲は、反撃の設計図になる。**

完全な自動戦闘には寄せず、マウス照準、敵の優先順位、射線、障害物、
回避方向をプレイヤー自身が判断する余地を残します。詳しい体験契約、
一戦内成長、Story / Endless / Practiceの役割は
[プロダクトコンセプト](../game-concept/)を最上位正本とします。

## 設計原則

- 四方の危険を、方向、原因、時刻、優先標的から読めるようにする。
- 上達が位置、射線、標的順、回収判断と結果へ反映されるようにする。
- 一戦は最小構成から始め、ラン中に通常強化とEX進行でCOREを完成させる。
- 危機を避けた後に、反撃、回収、位置改善へ使える結果を作る。
- 操作の忙しさだけを難しさにしない。
- 1回のランで、30秒から90秒ごとに意味のある判断を作る。
- 数値上昇だけでなく、開始武器、弾の挙動、敵構成で狙い方を変える。
- 大ダメージや特殊攻撃には予兆を付け、被弾理由を理解できるようにする。
- ランダム性は不公平な失敗ではなく、判断条件の変化に使う。
- ラン中の攻撃力、HP、強化、装備を次の一戦へ持ち越さない。
- 現在の通常25ランクが収束する間は、「毎回まったく異なるビルド」を約束しない。

## 継続して遊ぶ理由

やりこみは、次の要素で作ります。

- Story作戦と開始武器の固定解禁。
- 武器ごとの狙い方、最終強化、採用済みの分岐。
- 固定ルールのチャレンジ。
- 武器熟練度、実績、プロフィール統計。
- ローカルランキングとラン履歴。
- 別武器、別構成、PB、評価、戦術改善による再挑戦。

## 無料ゲームとしての方針

当面は、課金、ガチャ、広告を扱いません。

外部ログイン、バックエンド、オンラインランキングも、ローカルプロフィールと履歴で継続性を検証してから判断します。v1.0は、バックエンドなしで完結するローカルゲームを目標とします。

## 当面扱わないもの

- 恒久ステータス、素材、装備レアリティを中心とした周回作業。
- 大量の武器、ステージ、ボスの先行量産。
- 完全自動生成の障害物配置。
- 対人戦、協力プレイ。
- 長い会話やカットシーンを中心にしたStory。
- Storyの周回を戦闘力の前提にすること。
- 必要性が確認できていないアカウント同期。
